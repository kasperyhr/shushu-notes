# 六爻
目前为预留模块，待学习后填充。

六爻（又称纳甲筮法）是以三枚铜钱起卦、以卦象和爻象判断吉凶的占卜方法。计划覆盖以下主题：

- 起卦（铜钱起卦法）
- 装卦（纳甲、安世应、装六亲、装六神）
- 纳甲（天干地支纳入卦爻）
- 世应（世爻与应爻的定位与作用）
- 六亲（父母、兄弟、妻财、官鬼、子孙）
- 六神（青龙、朱雀、勾陈、螣蛇、白虎、玄武）
- 用神（确定所问之事的对应六亲）
- 元神（生用神的爻）
- 忌神（克用神的爻）
- 仇神（克元神的爻）
- 月建（占卜当月的时令力量）
- 日辰（占卜当天的时间力量）
- 空亡（旬空，暂时失力的爻）
- 动爻（老阳老阴变化产生的动爻）
- 变卦（动爻变化后形成的新卦）
- 伏神与飞神（卦中不见的六亲及其关系）
- 断卦（综合判断方法）
