# 阴阳变化与四象

## 核心结论

阴阳不是静态标签，而是变化趋势。四象（少阳、老阳、少阴、老阴）是阴阳动态变化的四个阶段，对应一天的时间、一年的四季，也是八卦和六十四卦的底层框架。

## 基本概念

### 四象

| 四象 | 含义 | 趋势 |
|------|------|------|
| 少阳 | 阳刚开始生 | 阴消阳长，阳气初起 |
| 老阳 | 阳达到极盛 | 阳气最旺，即将转折 |
| 少阴 | 阴刚开始生 | 阳消阴长，阴气初起 |
| 老阴 | 阴达到极盛 | 阴气最盛，即将转折 |

### 关键规律

**阴极生阳，阳极生阴。** 任何状态发展到极点，就会向对立面转化。这不是玄学，而是观察自然得出的规律：正午最热之后温度开始下降（阳转阴），午夜最冷之后温度开始回升（阴转阳）。

## 对应关系

### 一天中的四象

| 时段 | 四象 | 说明 |
|------|------|------|
| 清晨 | 少阳 | 阳气刚开始升起，温度开始回升 |
| 正午 | 老阳 | 阳气最旺盛，太阳在最高点 |
| 傍晚 | 少阴 | 阴气开始生长，温度开始下降 |
| 午夜 | 老阴 | 阴气最盛，温度最低 |

### 四季中的四象

| 季节 | 四象 | 说明 |
|------|------|------|
| 春 | 少阳 | 阳气初生，万物开始生发 |
| 夏 | 老阳 | 阳气极盛，万物繁茂 |
| 秋 | 少阴 | 阴气初生，开始收敛 |
| 冬 | 老阴 | 阴气极盛，万物收藏 |

## 现代理解

四象的本质，是任何一个周期过程的四个阶段。用现代概念来类比：

- **产品生命周期**：少阳 = 引入期（刚开始增长），老阳 = 成长期/成熟期（高速增长），少阴 = 衰退期（增速放缓），老阴 = 谷底（准备下一轮创新）。
- **项目推进**：少阳 = 启动阶段，老阳 = 执行高峰期，少阴 = 收尾阶段，老阴 = 复盘沉淀期。
- **学习任何技能**：都有"刚开始进步 → 快速提升 → 瓶颈期 → 沉淀突破"的四阶段循环。

## 易错点

- **老阳不等于"更好"**：老阳虽然是阳的极点，但也意味着即将走下坡路。正午虽然最亮，但接下来就是下午。
- **少阴不等于"变差"**：少阴虽然阴开始增长，但阴不是坏东西。傍晚虽然光线变暗，但也是休息和恢复的开始。
- **不要把四象当分类标签**：四象讲的是趋势，不是给人或事物贴标签。同一个项目在不同阶段对应不同的象。

## 速记

- 少阳 = 阳刚开始，像春天、清晨
- 老阳 = 阳到极点，像夏天、正午
- 少阴 = 阴刚开始，像秋天、傍晚
- 老阴 = 阴到极点，像冬天、午夜
- 核心规律：**阴极生阳，阳极生阴**
