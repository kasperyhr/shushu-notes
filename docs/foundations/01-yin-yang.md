# 阴阳基础

## 核心结论

阴阳不是好坏、善恶、吉凶。阴阳是两种相对的运动趋势：阳偏外放、上升、明亮、主动；阴偏内敛、下降、幽暗、安静。一切术数符号系统的最基本元件是阴爻和阳爻。

## 基本概念

### 阳

显现、主动、明亮、上升、外放、温热、开放、功能。

### 阴

隐藏、安静、幽暗、下降、内敛、寒凉、闭合、物质。

### 阴爻与阳爻

- 阳爻：———（一条连续的线）
- 阴爻：— —（中间断开的一条线）

六爻、八卦、六十四卦等系统的所有符号，都由这两种爻组合而成。它们是术数世界的基本粒子。

## 对应关系

| 属性 | 阳 | 阴 |
|------|----|----|
| 方向 | 上、外、升 | 下、内、降 |
| 光线 | 明亮 | 幽暗 |
| 温度 | 温热 | 寒凉 |
| 状态 | 主动、动态 | 安静、静态 |
| 功能/物质 | 偏功能 | 偏物质 |
| 爻符 | ——— | — — |

## 三个关键性质

### 1. 阴阳是相对的

没有绝对的阳，也没有绝对的阴。一个事物是"偏阳"还是"偏阴"，取决于你拿它跟谁比。白天的正午相对于清晨是阳，但正午相对于夏天的酷暑又偏阴。

### 2. 阴阳互根

阴和阳不能独立存在。没有上就没有下，没有热就没有冷，没有动就没有静。"互根"的意思是它们互为存在的前提，缺了对方，自己也就没有意义。

### 3. 阴阳消长

阴阳不是固定不变的，而是此消彼长的动态过程。阳增长的时候阴就在消退，阴增长的时候阳就在消退。这不是谁消灭谁，而是一种自然的节奏。

### 4. 阴阳转化

当阳发展到极致的时候，就开始向阴转化；阴发展到极致，就开始向阳转化。这跟四象（下一篇笔记会讲）直接相关：老阳之后是少阴，老阴之后是少阳。

## 现代理解

阴阳可以用来类比很多日常概念：

- **项目管理**：阳 = 执行的推进阶段，阴 = 规划和复盘阶段。不是哪个阶段更重要，而是二者交替进行才有健康的节奏。
- **学习过程**：阳 = 输入和输出（听课、做题、讨论），阴 = 消化和内化（思考、整理笔记、睡觉时大脑的巩固）。只学不消化会消化不良（阳过盛），只想不学是空转（阴过盛）。
- **计算机概念**：阳 ≈ CPU 运算（活跃、发热、做功），阴 ≈ 存储/待机（保存、冷却、准备）。

## 易错点

- **错把阴阳当善恶**：阳不是好，阴不是坏。一个人生病时阳气过盛可能是躁狂，阴气过盛可能是抑郁。阴阳讲的是状态，不是道德判断。
- **错把阴阳当成绝对的**：同样一个人，在运动场上偏阳，在图书馆里偏阴。阴阳是描述状态的工具，不是给人的标签。
- **别忘了阴阳互根**：很多人在讨论"补阳"时忘了阴。阴阳是互根的，阳需要阴作为基础才能不飘散。

## 速记

- 阳 = 放出去，阴 = 收回来
- 阳爻 = 一条线，阴爻 = 断开线
- 三个词概括阴阳的特性：**相对、互根、消长**
