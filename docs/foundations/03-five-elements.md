# 五行基础

## 核心结论

五行（木火土金水）不是五种物质，而是五种变化状态或趋势。它们描述的是事物从生发到收藏的完整生命周期。理解五行的关键是抓住每种状态的"动作方向"，而不是具体实物。

## 基本概念

### 五行逐条解析

**木 — 生发**

向外、向上、开始、萌发、生长、舒展。像春天树木发芽，一切刚开始往外冒。

**火 — 旺盛**

热烈、爆发、显耀、活跃、高峰。像夏天万物繁茂，能量达到顶点。

**土 — 承载、转化、过渡**

稳定、包容、消化、承接、中转。像四季交接的过渡期，把上一阶段的成果消化吸收，为下一阶段做准备。

**金 — 收敛、成形、规则**

向内收缩、定形、整理、规范、切割。像秋天果实成熟、收割、落叶归根，一切从扩张转为收敛。

**水 — 收藏、潜藏、蓄积**

下沉、内藏、沉淀、积蓄、准备。像冬天万物蛰伏，把能量收起来、藏起来，等春天再释放。

### 关于水的"收藏"

水的"收藏"不是收集东西，而是：收起来、藏起来、蓄起来、暂时不外放。水不是死，而是藏——是为了下一轮生发做准备。没有冬天的积蓄，春天拿什么来发？

## 现代理解

五行是一个五阶段循环模型，类似于：

- **项目管理**：木 = 项目启动，火 = 全力推进，土 = 中期评估和调整，金 = 交付和规范化，水 = 复盘归档准备下一次迭代。任何一个健康的项目都会经历这五个阶段。
- **知识学习**：木 = 开始接触新领域，火 = 大量吸收和练习，土 = 整理和内化，金 = 形成体系、可以输出，水 = 沉淀之后发现新的知识缺口（开始下一轮木）。

## 易错点

- **别把五行当元素周期表**：五行不是五种基本物质。一个事物可以同时表现出多种五行特性，取决于你从哪个角度观察。
- **金不只是金属**：金代表的是收敛、成形、规则的特性。法律、纪律、切割、手术，这些都带有金的属性。
- **土不是可有可无的**：土是转化的枢纽。在五行循环中，土是连接其他四行的关键节点。四季交接的"土旺"阶段，就是用来消化和过渡的。

## 速记

- 木 = 往外冒（生发）
- 火 = 往上冲（旺盛）
- 土 = 稳下来消化（承载转化）
- 金 = 收回来定型（收敛成形）
- 水 = 藏起来沉淀（收藏蓄积）
