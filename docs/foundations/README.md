# 基础篇：阴阳五行与干支

## 本模块包含

这是术数学习的根基。无论以后学六爻、大六壬、奇门遁甲还是梅花易数，以下概念都会反复出现：

- 阴阳基础
- 四象与阴阳变化
- 五行（木火土金水）
- 五行相生、相克
- 生克关系中的通关与旺衰
- 十天干
- 十二地支
- 生肖与地支
- 六合、六冲、三合、三会

## 推荐学习顺序

按编号顺序阅读，不要跳。阴阳之后立即学四象，因为四象是阴阳的动态展开。五行的五篇要连在一起读，因为生克和旺衰是互相关联的。天干和地支可以分开学，但地支关系的三篇（六合六冲、三合三会）需要按顺序。

## 本模块定位

本模块的目标是**打基础和做速查**，不是完整的断法教程。学完之后你应该能：

- 理解阴阳五行的基本逻辑
- 说出十天干、十二地支的名称、五行和基本象意
- 列出六合、六冲、三合、三会的组合
- 理解生克的本质不是简单的好坏判断

本模块不教任何具体术数的起卦、排盘和断法。
