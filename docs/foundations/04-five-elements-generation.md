# 五行相生

## 核心结论

相生不是"生出一个新东西"，而是提供条件、滋养、推动、增强。木生火 = 生长推动旺盛，火生土 = 旺盛之后需要承载消化，土生金 = 沉淀后成果成形，金生水 = 收敛后进入收藏，水生木 = 储备后重新生发。相生不一定是好事——如果被生的是不利因素，麻烦也会被增强。

## 基本概念

### 相生顺序

```
木 → 火 → 土 → 金 → 水 → 木
```

### 逐条理解

| 相生关系 | 解释 |
|----------|------|
| 木生火 | 生长推动旺盛。木材能让火烧得更旺，从萌发到爆发是自然的递进。 |
| 火生土 | 旺盛之后需要承载和消化。火烧完之后留下灰烬（土），爆发之后需要沉淀。 |
| 土生金 | 沉淀之后成果成形。土里埋藏的矿物经过沉淀变成了金属，消化之后产出成果。 |
| 金生水 | 收敛之后进入收藏和沉淀。金属冷却后表面凝结水珠，整理完了就归档保存。 |
| 水生木 | 储备之后重新生发。水滋养植物生长，积蓄够了就开始新一轮。 |

## 对应关系

### 相生链中的五行角色

| 生者（母） | 被生者（子） | 关系类型 |
|------------|-------------|----------|
| 木 | 火 | 木是火的"母亲" |
| 火 | 土 | 火是土的"母亲" |
| 土 | 金 | 土是金的"母亲" |
| 金 | 水 | 金是水的"母亲" |
| 水 | 木 | 水是木的"母亲" |

在术数中常把生者称为"母"，被生者称为"子"。

## 现代理解

相生关系可以用很多现代场景类比：

- **软件开发**：需求分析（木）生架构设计（火）生代码实现（土）生测试交付（金）生运维沉淀（水）生新一轮需求分析（木）。
- **写作过程**：灵感萌芽（木）生激情写作（火）生整理修改（土）生定稿规范（金）生沉淀反思（水）生新的灵感（木）。

## 易错点

- **相生不一定吉**：木生火，但如果木代表"压力"、火代表"焦虑"，那压力越大焦虑越重，这不是好事。相生是"增强"，增强的是好还是坏要看具体情境。
- **别用字面意思想象**："土生金"不是土里长出金子，"金生水"不是金属里面有水。要从功能和趋势的角度理解。
- **生者不一定强于被生者**：水能生木，但水本身不一定是力量最强的那个。关键看旺衰。

## 速记

- 相生口诀：**木火土金水，循环相生**
- 一句话：生 = 推动、滋养、增强
- 木→火（长→旺）、火→土（旺→化）、土→金（化→成）、金→水（成→藏）、水→木（藏→长）
