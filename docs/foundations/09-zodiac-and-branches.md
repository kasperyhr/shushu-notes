# 十二生肖与地支

## 核心结论

生肖是地支的形象化表达。地支是本体，生肖是象。术数判断时，核心是地支的五行、生克、冲合和旺衰，不是直接看生肖动物。单看生肖不能完整判断命理。

## 对应关系

生肖之所以"附"在地支上，是为了方便记忆和形象化。但真正起作用的是地支本身携带的信息：

- **子**：水、北方、十一月、深夜
- **午**：火、南方、五月、正午
- 等等

"属鼠的人"术数上的含义是"出生年地支为子的人"，接下来看子水在命局中的旺衰、与其他地支的冲合关系、天干配合等等，而不是看"老鼠"怎么怎么样。

## 现代理解

生肖和地支的关系，就像：

- **图标和程序**：你点击图标（生肖鼠）打开程序（地支子），但真正运行的是程序代码（五行、生克、旺衰），图标只是让你更快找到它。
- **姓名和身份证号**：生肖是"名字"，地支是"身份证号"。名字好记，但真正查询信息时用的是身份证号。

## 易错点

- **属什么不等于命好命坏**："属龙就是好命"是没有依据的。龙对应辰土，辰土在命局里是要看它在什么位置、被什么生克、旺衰如何。
- **生肖配对不可靠**："属鸡和属狗不合"这种民间说法忽略了整个命局。酉（鸡）和戌（狗）虽然相害，但不能单看这一点判断两个人的关系。
- **生肖不是判断核心**：任何术数系统判断时，用的都是地支的五行和生克冲合关系，不是生肖动物的习性。

## 速记

生肖顺序就是地支顺序：**子鼠、丑牛、寅虎、卯兔、辰龙、巳蛇、午马、未羊、申猴、酉鸡、戌狗、亥猪**
