# 十天干

## 核心结论

十天干是五行在"天"这个层面的细化：甲乙属木、丙丁属火、戊己属土、庚辛属金、壬癸属水。每对天干中，前者为阳（甲丙戊庚壬），后者为阴（乙丁己辛癸）。天干比五行更具体，有了阴阳属性和象意，是术数排盘的基础元素。

## 基本概念

### 十天干列表

十天干：**甲 乙 丙 丁 戊 己 庚 辛 壬 癸**

### 五行分类

| 五行 | 阳干（刚、显） | 阴干（柔、隐） |
|------|---------------|---------------|
| 木 | 甲 | 乙 |
| 火 | 丙 | 丁 |
| 土 | 戊 | 己 |
| 金 | 庚 | 辛 |
| 水 | 壬 | 癸 |

### 各天干象意

| 天干 | 五行 | 阴阳 | 象意 |
|------|------|------|------|
| 甲 | 木 | 阳 | 大树、栋梁、参天巨木 |
| 乙 | 木 | 阴 | 花草、藤蔓、柔韧之木 |
| 丙 | 火 | 阳 | 太阳、烈日、光明正大 |

## 对应关系

### 阳干与阴干的区别

| 对比维度 | 阳干 | 阴干 |
|----------|------|------|
| 气质 | 刚健、外向、显现 | 柔顺、内向、含蓄 |
| 作用方式 | 直接、猛烈 | 间接、细密 |
| 类比 | 甲木像大树，硬碰硬 | 乙木像藤蔓，缠绕渗透 |

### 天干与方向

| 天干 | 方向 |
|------|------|
| 甲乙 | 东 |
| 丙丁 | 南 |
| 戊己 | 中 |
| 庚辛 | 西 |
| 壬癸 | 北 |

## 现代理解

天干的阴阳之分可以用现代职场类比：

- **甲（阳木）**像 CEO，正面统领，旗帜鲜明
- **乙（阴木）**像幕僚或顾问，不正面出场，但影响力渗透深远
- **丙（阳火）**像发布会、公开演讲，光芒四射
- **丁（阴火）**像私下沟通、一对一辅导，细微但持久
- **庚（阳金）**像法庭判决、规章制度，硬性切割
- **辛（阴金）**像精细工艺、审美标准，润物细无声

阴不等于弱，阳不等于强。一个优秀的幕僚（乙）的影响力可以远超一个平庸的 CEO（甲）。

## 易错点

- **阴干不等于弱**：癸水（阴水）看起来像小小的雨露，但持续不断的雨水可以穿透岩石。乙木（藤蔓）也能勒死大树。
- **阳干不一定比阴干好**：阳干显眼、直接，但阴干灵活、渗透。不同情境各有优势。
- **天干的象意不是字面实物**："甲 = 大树"是帮助你记忆的意象，不是说每次甲出现都代表树。

## 速记

- 顺序：**甲乙丙丁戊己庚辛壬癸**
- 五行分组：甲乙木、丙丁火、戊己土、庚辛金、壬癸水
- 阴阳：奇数位（甲丙戊庚壬）为阳，偶数位（乙丁己辛癸）为阴
- 象意：甲大树乙花草、丙太阳丁灯烛、戊高山己田园、庚刀斧辛珠玉、壬江河癸雨露
