# 十二地支

## 核心结论

十二地支是天干的落地坐标：子丑寅卯辰巳午未申酉戌亥。它们各有五行归属、阴阳属性、对应方位、代表月份和时辰。地支比天干更"实"，因为它对应具体的时间、空间和旺衰位置，是很多术数系统的基础坐标。

## 基本概念

十二地支：**子 丑 寅 卯 辰 巳 午 未 申 酉 戌 亥**

**地支五行分类**

| 五行 | 地支 |
|------|------|
| 水 | 亥、子 |
| 木 | 寅、卯 |
| 火 | 巳、午 |
| 金 | 申、酉 |
| 土 | 辰、戌、丑、未 |

注意：土的地支有四个（辰戌丑未），被称为"四库"或"四墓"。

**四正（方位正中之位）**

| 地支 | 方位 | 五行 | 说明 |
|------|------|------|------|
| 子 | 北方 | 水 | 正北，水最旺之位 |
| 午 | 南方 | 火 | 正南，火最旺之位 |
| 卯 | 东方 | 木 | 正东，木最旺之位 |
| 酉 | 西方 | 金 | 正西，金最旺之位 |

**地支与月份**

| 季节 | 地支 | 传统建月 | 说明 |
|------|------|-----------|------|
| 春 | 寅、卯、辰 | 正月、二月、三月 | 以节气划分为主，不完全等同农历月份 |
| 夏 | 巳、午、未 | 四月、五月、六月 | 以节气划分为主 |
| 秋 | 申、酉、戌 | 七月、八月、九月 | 以节气划分为主 |
| 冬 | 亥、子、丑 | 十月、十一月、十二月 | 以节气划分为主 |

术数中的月建主要按节气划分，上表中的"正月、二月"等是传统习惯称呼，不要误以为月建完全按农历初一切换。

## 对应关系

地支为什么比天干更"实"？因为它对应着：

- 月份（时令旺衰）
- 时辰（一天中的时段）
- 方位（空间坐标）
- 实际排盘位置

在六爻、六壬、奇门等实际排盘时，地支是必须落在具体位置上的坐标，而不仅仅是抽象属性。

## 现代理解

天干 vs 地支可以类比为：

- **天干 = 战略意图**，地支 = 实际执行的时间和地点
- 天干说"我们要在这个方向发力（五行）"，地支说"什么时候（月份）在哪里（方位）以什么状态（旺衰）执行"

四正就像四个锚点，把抽象的五行钉在了具体的地理方位上。

## 易错点

- **地支不仅有四个土**：辰戌丑未都是土，但它们各有偏重——辰是湿土（偏水）、戌是燥土（偏火）、丑是寒土（偏金）、未是热土（偏木）。不能把它们当一样的土来用。
- **地支不是十二生肖**：生肖是地支的形象化表达，地支才是本体。判断时用的是地支的五行和关系，不是生肖动物。
- **四正不是"最好的四个"**：四正只是方位最正、五行最纯的四个地支，不是说子午卯酉就一定比其他地支好。

## 速记

- 地支顺序：**子丑寅卯辰巳午未申酉戌亥**
- 五行分组：亥子水、寅卯木、巳午火、申酉金、辰戌丑未土
- 四正：子北水、午南火、卯东木、酉西金
- 月份季节：寅卯辰春、巳午未夏、申酉戌秋、亥子丑冬
