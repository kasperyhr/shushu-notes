# 从这里开始

## 这个知识库是什么

这是一份个人术数学习笔记，目的是把从零开始学到的内容整理成可复习、可检索的知识体系。它不是课程讲义，不会提供练习题或"标准答案"；它更像是你在学习过程中自己整理的笔记，只不过现在以 Markdown 的形式组织起来了。

## 怎么使用

1. **按顺序阅读基础篇**：从 [阴阳基础](/docs/foundations/01-yin-yang.md) 开始，按编号顺序一篇一篇往下读。每篇笔记只聚焦一个主题，内部有充足的表格和链接。
2. **用速查表辅助记忆**：[速查表](/docs/foundations/tables.md) 汇总了所有核心对照表，适合复习和快速查阅。
3. **用术语表查漏补缺**：[术语表](/docs/foundations/glossary.md) 按字母顺序收录了核心术语，碰到不认识的词可以快速定位。
4. **当字典用**：学六爻、大六壬等具体术数时，随时回到基础篇查阅某个概念。

## 不要跳过基础

阴阳、五行、天干、地支、冲合会这些概念，会在后续六爻、大六壬、奇门遁甲、梅花易数等体系中反复出现。基础不牢，后面每篇都像是在读天书。反之，如果基础打扎实了，你会发现不同术数之间有很多共同的底层逻辑。

## 笔记风格

每篇笔记大致遵循以下结构，但不会死板地全部一致：

- **核心结论**：几句话讲清楚本篇最重要的事
- **基本概念**：术语和基础定义
- **对应关系**：用表格整理需要记忆的关联
- **现代理解**：用现代类比帮助理解
- **易错点**：整理容易误解的地方
- **速记**：口诀、关键词、最小记忆单元
- **相关笔记**：链接到其他相关文件
